# 成都闲逛 HangoutChengdu

一个可以在手机网页端运行的3D休闲驾驶游戏，让玩家在虚拟的成都街头自由探索。

## 🎮 游戏简介

在成都的街头骑车闲逛，探索这座城市的各个角落。游戏中包含了成都的著名地标，如天府广场、春熙路、宽窄巷子等。没有胜利条件，只是自由地探索和享受驾驶的乐趣。

### 特点
- 🌆 3D城市环境，包含道路网络和建筑
- 🏍️ 简单的车辆物理系统
- 📍 成都著名地标和景点
- 📊 玩家成长系统（追踪行驶距离、时间等）
- 📱 支持移动端和PC端
- 🎯 无需安装，浏览器直接运行

## 🚀 如何运行

### 方式一：本地运行（推荐）

由于浏览器的安全限制，建议使用本地服务器运行：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Python 2
python -m SimpleHTTPServer 8000

# 或使用 Node.js (需要先安装 http-server)
npx http-server -p 8000
```

然后在浏览器中打开 `http://localhost:8000`

### 方式二：直接部署

将项目上传到任何静态网站托管服务：
- GitHub Pages
- Netlify
- Vercel
- 或任何支持静态文件的服务器

## 🎯 游戏操作

### PC端控制
- **W / ↑** - 前进
- **A / ←** - 左转
- **D / →** - 右转
- **空格** - 刹车
- **R** - 重置车辆位置

### 移动端控制
- 使用屏幕底部的虚拟按钮
- **↑** - 前进
- **←** - 左转
- **→** - 右转
- **⬛** - 刹车

### 如何添加新地标

在 `game.js` 文件中找到 `CHENGDU_LANDMARKS` 数组，添加新的地标：

```javascript
const CHENGDU_LANDMARKS = [
    // ... 现有地标
    { 
        name: '新地标名称', 
        position: { x: 100, z: 200 },  // 设置位置
        color: 0xFF0000  // 设置颜色（十六进制）
    }
];
```

### 如何调整游戏参数

在 `game.js` 文件顶部的 `CONFIG` 对象中修改：

```javascript
const CONFIG = {
    vehicleSpeed: 0.3,        // 车辆加速度
    vehicleTurnSpeed: 0.03,   // 转向速度
    vehicleBrake: 0.95,       // 摩擦力/减速
    cameraOffset: new THREE.Vector3(0, 8, 15),  // 相机位置
    worldSize: 1000,          // 世界大小
    blockSize: 50,            // 街区大小
    buildingDensity: 0.3      // 建筑密度 (0-1)
};
```
